# oscarmendez.co.uk

Personal website of Dr Oscar Mendez, hosted on GitHub Pages.

## How it's organised

| Folder | What it is |
|---|---|
| `source/` | What you edit. `oscarmendez-site.html` is the whole site in one file (open it in a browser to preview every page). Also `llms.txt`, `og-image.png` and, once added, `OscarMendezCV.pdf`. |
| `docs/` | What GitHub publishes. **Generated by the build script; don't edit by hand.** |

## Updating the site

1. Edit `source/oscarmendez-site.html` (or `llms.txt`, or replace the CV PDF).
2. Rebuild from the repository root:
   ```
   python3 source/build.py
   ```
   This regenerates `docs/` with one real page per section, the sitemap, robots.txt, llms.txt, the 404 page and the custom-domain file.
3. Commit and push. GitHub Pages republishes within a minute or two.

Requires Python 3 only, no extra packages.

## First-time setup

1. Create a repository on GitHub (e.g. `oscarmendezm/oscarmendez.co.uk`) and push this folder to its `main` branch.
2. In the repository: **Settings → Pages → Build and deployment**, choose *Deploy from a branch*, branch `main`, folder `/docs`.
3. Under **Custom domain**, confirm `oscarmendez.co.uk` (the `docs/CNAME` file sets this).
4. In **GoDaddy → My Products → oscarmendez.co.uk → DNS**:
   - Turn off the existing forwarding to cvssp.org.
   - Set the `@` A records to GitHub Pages' four IP addresses (listed in GitHub's docs under *Managing a custom domain for your GitHub Pages site*), replacing any existing `@` A record.
   - Set `www` as a CNAME pointing to `oscarmendezm.github.io`.
   - **Leave all MX and TXT records exactly as they are.** They deliver email for me@oscarmendez.co.uk via Google Workspace.
5. Once GitHub shows the DNS check as successful, tick **Enforce HTTPS**.

## After it's live

- Add the site to Google Search Console and Bing Webmaster Tools, and submit `https://oscarmendez.co.uk/sitemap.xml`.
- Put `https://oscarmendez.co.uk` in the website field of LinkedIn, Google Scholar, ORCID, GitHub and the University of Surrey profile.
